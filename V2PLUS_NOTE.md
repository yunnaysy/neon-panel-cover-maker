# v2-plus (preview branch)

This is the user-approved v2-plus preview. It keeps the v2 look and adds:
- undo/redo
- lettering size and position controls, with drag, a 9-position grid and auto-fit
- per-layer fonts and 6 lettering templates
- "Entire poster / Selected panel" colour scope
- "lettering below photos", so every panel stays visible
- tablet and mobile layout with a bottom sheet

The preview was hand-built and lives on this branch only. The contest entry on `main` is rebuilt by a recorded coding agent from a feature spec.
Live: https://yunnaysy.github.io/neon-panel-cover-maker/
